12 / 易踩的坑 → 数据质量规则
DON'T · 易踩的坑
由名称或菜单分组推断启停状态
猜补省略号截断的描述内容
用显示名称做查询与绑定
把 Plugin 当成独立运行时
⟶
DO · 质量规则
状态缺失显示「未提供」，不推断
截断摘要从详情页读取完整记录
以英文标识 / 数据库 ID 为准
权限与审计规则由授权与实现定义
